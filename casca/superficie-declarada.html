Uma superfície declarada

Isto não é uma tela. É a informação que esta superfície precisa mostrar, em HTML sem uma linha de CSS. Gerado de conteudo/superficie-declarada.json — não edite este arquivo.

o que ela faz

Um serviço integrado descreve a tela dele num contrato SEM cor, fonte ou medida, e o okmigo a desenha nativamente — nunca roda código de terceiro dentro do app. O que se desenha aqui não é uma tela: é o VOCABULÁRIO que serve toda superfície de todo serviço, nos dois clientes.

quem abre

Quem instalou aquele serviço. A tela é dele; o desenho é nosso.

o que precisa sobreviver ao redesenho

  • Uma superfície mostra UMA lista.
  • NÃO existe aba. Uma tela com três seções independentes quer navegação, e navegação não está no vocabulário.
  • A única cor que o serviço escolhe é a de uma SÉRIE de gráfico, por nome semântico (positivo/negativo/neutro/atenção) — nunca por valor.
  • Cada peça precisa desenhar IGUAL no web e no Flutter. Uma que difere transforma o contrato em sugestão.
